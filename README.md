This is an autonomous bot I built for the game GridWars using Processing (Java). The bot uses a simple but effective strategy to claim space on the grid: it first checks for any unclaimed tiles nearby and moves toward them, and if none are available, it switches to a BFS‑based pathfinding method to locate the nearest unclaimed block.

The project helped me practice grid traversal, game loops, and implementing BFS from scratch. It also taught me how to structure logic for autonomous behavior and work with inherited methods from the game engine.

Tech: Processing (Java), BFS pathfinding, game loops, state management
